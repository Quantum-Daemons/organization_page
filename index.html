Quantum-safe networking, checked in public.

Quantum Daemons is a one-person research organization in Japan. I measure and test hybrid post-quantum (PQC) and quantum key distribution (QKD) setups in open-source VPN and key-management software, and publish the code and the counting rules behind each result so that others can check it.

It is not a consultancy. Each result states what was tested, in which versions and configuration, and how it was evidenced.

How each claim is labelled

Results and reports carry one of these labels per layer, so a reader can see what kind of evidence stands behind each statement.

merged upstream
The change is in the project's main code, and the pull request is linked.
measured
Counted from logs in a stated time window, with the counting script and the counts published. Raw logs that carry credential IDs or host identities are withheld. Nothing is claimed outside that window.
running
The component runs in the public testbed at the version pinned in its repository. This shows that it works there, not that it is correct or released.
official vectors
Output matches test vectors published by the owner of the standard, such as NIST ACVP.
computed from the spec
Implemented from the specification where no official vectors exist. A passing self-test here is not proof of correctness.
two implementations agree
Independent implementations produce the same result. This shows consistency, not correctness.
classical baseline
Compared with a classical method given the same budget, with seeds and statistics published. The result is reported whichever way it falls.
simulated
Physics or networks are modelled from published data, not measured. The QKD layer of the testbed is simulated.

What this is not

  • Not a consultancy: no advisory engagements, no meetings as a product, no priority support.
  • No certification or compliance statements. A result covers the versions, configuration and time window it names.
  • No quantum hardware. The QKD layer in the testbed is simulated.
  • No claims of quantum advantage.
